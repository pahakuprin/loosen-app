# loosen-app

Экран колокольчика: «Во что вовлёкся?» → их слова в кавычках → точка. Ставится на телефон
как приложение, работает без сети. Почему выглядит и ведёт себя так — [DESIGN.md](DESIGN.md).

Второе воплощение хода, который живёт отдельно скиллом для агента; сам скилл в этот
репозиторий не входит, ссылки на его файлы в документах — про соседний каталог.

## Запустить локально

Модули ES и сервис-воркер не работают с `file://` — нужен любой статический сервер.
Из каталога репозитория:

```bash
python3 -m http.server 8107 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8107/>.

## Проверить

```bash
node --test test/
```

14 случаев из `../loosen/evals/evals.json` на словаре фикстур, каждая реплика уходит
в линтер скилла `../loosen/scripts/lint-reply.mjs`, плюс края и такты. Случай 14 (реальная
беда) помечен `todo`: без модели он не решается, см. DESIGN.md, слой 4.

Реальная каденция тактов, при поднятом сервере и Chrome в /Applications:

```bash
node tools/time-beats.mjs
```

Печатает секунды от Enter до появления каждого такта. Встроенная панель браузера для этого
не годится: скрытая вкладка тормозит таймеры страницы.

## Поставить на телефон

Нужен адрес по HTTPS (любой статический хостинг: GitHub Pages, Cloudflare Pages, папка
на своём сервере). Без HTTPS сервис-воркер не поднимется и офлайна не будет; сама страница
работать будет. Сборки нет: на Pages кладётся корень репозитория как есть, все ссылки
относительные и работают из подкаталога.

- **iPhone.** Safari → адрес → «Поделиться» → «На экран „Домой“». Иконка — точка на бумаге.
  Откроется без адресной строки, в портрете.
- **Android.** Chrome → адрес → меню → «Установить приложение» (или «Добавить на главный
  экран»).

После установки сеть не нужна: все файлы в кэше. Обновление: поменять `VERSION` в `sw.js`,
кэш пересоберётся при следующем открытии — открыть приложение может понадобиться дважды:
первый раз ставится новый воркер, второй показывает новые файлы.

Полоса статуса — три ловушки, и все дают нечитаемые знаки. На iPhone её задаёт
`apple-mobile-web-app-status-bar-style`, годится только `default`: `black-translucent` всегда
красит знаки белым, и на светлой теме они пропадают. На Android установленное приложение
красит полосу цветом из манифеста, а в манифесте цвет может быть только один на обе темы —
поэтому ни `theme_color`, ни `background_color` там нет, полоса идёт от темы системы.
Медиазапрос на `theme-color` читают не все: кто не читает, берёт первый тег и держит его цвет
в обеих темах, поэтому цвет во всех тегах ставит `paintBars` в `app.js` — цвет текущей бумаги.

Манифест читается при установке: чтобы правка в нём дошла, приложение переставляют.

## Где что менять

| что | где |
|---|---|
| слова: `caught`, `signal`, `when` | `words.js` — копия `~/.claude/loosen/WORDS.md`; `caught` — вопрос целиком («Во что вовлёкся?») или слово («держит» → «Что держит?») |
| неизменные строки (ru/en) | `LINES` в `bell.js` |
| словари ветвления, эвристика цитаты | `bell.js` |
| тайминги паузы и тактов | `T` в `app.js` |
| цвета, шрифт, кегль | `app.css`, блок `:root` |
| имя на иконке | `manifest.webmanifest`, `index.html` (`apple-mobile-web-app-title`, `title`) |
| иконки | `python3 tools/make-icons.py` (нужен Pillow) |

## Файлы

```
index.html            разметка: строка и поле
app.css               один экран, светлая и тёмная пара
app.js                время, поле, клавиатура, регистрация сервис-воркера
bell.js               ход как чистые функции; словари; выбор цитаты
words.js              их слова
sw.js                 кэш всех файлов
manifest.webmanifest  установка на экран «Домой»
icons/                точка на бумаге: svg, 192, 512, maskable, apple-touch
tools/make-icons.py   генератор иконок
tools/time-beats.mjs  реальная каденция тактов в headless Chrome
test/bell.test.mjs    node --test
DESIGN.md             откуда взято каждое решение
```

## Чего нет

- Первого запуска с тремя вопросами (шаг [0] скилла) — слова захардкожены.
- Модели: самая короткая фраза выбирается эвристикой, беда не распознаётся.
- Истории, счётчиков, звука, настроек — намеренно, см. DESIGN.md.
